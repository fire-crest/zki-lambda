# zoom-kit-add-contact-to-webinar (Node.js)

The Node.js version of the function that registers a Kit subscriber for a Zoom
webinar or meeting. It does the same job as the Python version.

See [`zoom-kit-add-contact-to-webinar-python/README.md`](../zoom-kit-add-contact-to-webinar-python/README.md)
for how it works, the event it receives from Kit, and the services it uses.
